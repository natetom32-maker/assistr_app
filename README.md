# TurfProsa landing page

A responsive, single-page marketing site for TurfProsa (turfprosa.com). The site highlights services, recent projects, process, and a contact form with smooth navigation.

## Preview locally
Open `index.html` in your browser or serve the folder with any static file server.

```bash
# Using Python
python -m http.server 8000
# Then visit http://localhost:8000
```
